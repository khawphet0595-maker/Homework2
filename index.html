เหตุผลที่อยากเรียน Full Stack Web Development

ผมสนใจการพัฒนาเว็บไซต์และต้องการเรียนรู้การสร้างเว็บไซต์ ตั้งแต่ส่วนหน้าบ้านไปจนถึงส่วนหลังบ้าน เพื่อให้สามารถสร้าง เว็บไซต์หรือระบบที่สามารถใช้งานได้จริง

ความคาดหวังต่อวิชานี้

คาดหวังว่าจะได้เรียนรู้การเขียนเว็บไซต์อย่างเป็นระบบ สามารถสร้างเว็บไซต์ด้วย HTML และเข้าใจพื้นฐานของ Front-end และ Back-end รวมถึงสามารถนำความรู้ไปประยุกต์ใช้ ในการทำงานและการพัฒนาโปรเจกต์ในอนาคตได้

ความรู้หรือทักษะที่ต้องการพัฒนา

ต้องการพัฒนาทักษะด้าน Programming การเขียน HTML การออกแบบโครงสร้างเว็บไซต์ การแก้ไขปัญหาจากการเขียนโปรแกรม และการพัฒนาเว็บไซต์ให้สามารถใช้งานได้จริง

แนวทางการพัฒนาตนเอง

  • ฝึกเขียนโปรแกรมอย่างสม่ำเสมอ
  • ศึกษาตัวอย่างเว็บไซต์และโค้ดจากแหล่งเรียนรู้ต่าง ๆ
  • ทดลองสร้างเว็บไซต์ด้วยตนเอง
  • ฝึกแก้ไขปัญหาและข้อผิดพลาดจากการเขียนโปรแกรม
  • นำความรู้ไปสร้างโปรเจกต์จริง

เว็บไซต์ที่ชื่นชอบและเป็นแรงบันดาลใจ

เว็บไซต์ที่ผมสนใจคือ YouTube เพราะสามารถใช้ค้นหาความรู้และเรียนรู้การเขียนโปรแกรม จากวิดีโอต่าง ๆ ได้
